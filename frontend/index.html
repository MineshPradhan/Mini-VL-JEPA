Mini VL-JEPA / captioning without token generation

A compact video-language model that predicts multilingual sentence embeddings from frozen V-JEPA 2 features, and invokes a text decoder only when the latent state changes — selective decoding for streaming video.

❄ V-JEPA 2 encoder — frozen ▲ JEPA predictor ≈ 60M — trainable ❄ LaBSE target space — frozen ▲ mT5-small decoder — LoRA

01 · Architecture

Only the violet blocks are trained. Everything blue is a frozen open-weight checkpoint — which is why this runs on a single GPU.

02 · Latent trajectory scope

Press Stream. The violet trace is the predicted embedding ẑ drifting through (PCA-projected) LaBSE space as the video plays. When drift from the last decoded point crosses the threshold τ, the decoder fires — a green pulse — and a bilingual caption lands in the event log. Drag τ and watch the compute savings change.
